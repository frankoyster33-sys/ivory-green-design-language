# 资源目录

所有示例均为通用设计样张，不包含真实机构、业务或产品案例。

| 文件 | 用法 |
| --- | --- |
| [tokens.json](../assets/tokens.json) | 跨工具抄录的颜色、字体角色与间距基准；普通 JSON，不声称符合特定外部 token 标准 |
| [editorial.css](../assets/editorial.css) | `.ig` 命名空间下的网页视觉起点，避免污染宿主页面 |
| [starter.html](../assets/starter.html) | 可离线打开的交互样张；与 CSS、JS 同目录保留 |
| [starter.js](../assets/starter.js) | 预览画布切换与可重置的自检演示，无网络请求、无数据存储 |
| [preview.svg](../assets/preview.svg) | 1600 × 900 通用封面，可作仓库预览 |
| [slide-16x9.svg](../assets/templates/slide-16x9.svg) | 1920 × 1080 矢量演示版式 |
| [poster-portrait.svg](../assets/templates/poster-portrait.svg) | 1080 × 1440 矢量竖版海报 |
| [diagram.svg](../assets/templates/diagram.svg) | 通用矢量流程示意 |

SVG 中保留文字和分组，可以编辑 XML 或导入支持 SVG 的工具。导入 PowerPoint 或 Photoshop 后的可编辑程度取决于应用；这些文件不是原生 PPTX 或分层 PSD。需要这些原生格式时按制作指南重新构建原生文本与图层，不把整张 SVG 插入当作完成全部可编辑内容。

样张中的标题和说明需要换成当前任务的内容，不要复制无关的展示文字。圆角、字号和密度可以调整；不要依赖固定行数才能成立的布局。
