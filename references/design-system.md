# 视觉基础

## 气质与取舍

关键词：温润、清晰、编辑感、安静的秩序。识别点是浅色画布、深绿结构和有呼吸感的排版。减少装饰不等于删除内容；需要高密度时，依靠网格、分组和对齐组织信息。

把以下数值当作可调整的起点。保留角色关系，优先满足阅读距离、设备尺寸和用户指定规范。

## 色彩角色

| Token | HEX | 用途 |
| --- | --- | --- |
| paper | #F9F4EC | 米白画布、说明区、柔和分组 |
| white | #FFFFFF | 正文画布、控件、局部提亮 |
| forest | #134436 | 标题、重点底色、结构主色 |
| green | #006442 | 链接、主动作、选中态 |
| ink | #203D34 | 浅色背景上的正文 |
| muted | #50665C | 次级文字，仍需清晰可读 |
| line | #D7DFD3 | 分隔线、装饰边界，不单独承担控件识别 |
| accent | #FFE552 | 少量标记、深底关键数字，配深色文字 |
| canvas | #F1F0E9 | 网页外层画布，可选 |

大面积保持白/米白；绿色组织阅读；亮黄只保留在少量关键位置。不要把面积比例变成机械配额。避免白字配亮黄、米白字配浅线色。需要错误/警告时可引入克制的语义色，同时给出文字或图标，不为了统一绿色而牺牲含义。

正文优先 ink / paper 或 ink / white；深色区用 paper / forest 或 white / forest；主按钮 white / green；重点数字 accent / forest。每次改透明度、叠图或颜色后重新检查实际对比度。浅线只作装饰，输入框边界和焦点环用可辨认的更深颜色。

## 字体与语言

| 场景 | 标题建议 | 正文/控件建议 |
| --- | --- | --- |
| 英文 | Georgia、Times New Roman，或具备授权的编辑型衬线体 | Inter（已安装时）、Arial、system sans |
| 简体中文 | Noto Serif SC、Source Han Serif SC、Songti SC、SimSun 中可用的一种 | Noto Sans SC、PingFang SC、Microsoft YaHei、system sans |
| 繁体中文 | 对应 TC 繁体字形字体，或系统可用的宋体类 | 对应 TC 黑体类或系统黑体 |
| 混排 | 按语言分配字族，检查数字和标点 | 数值界面可用 tabular-nums |

一个作品通常使用一组标题体、一组正文体，避免每页换字体。上述为字体候选，不代表设备已安装；字体文件不随本仓库分发。字体嵌入、再分发和商用按对应授权办理。不可把系统字体存在于制作者电脑当作接收方也有。

英文大标题可略收字距（约 −0.02em 到 −0.04em）；中文从正常字距开始，行高 1.25–1.4。细字重不适合投影、低分辨率截图和小字号。英文大写短眉题可用 0.1em 字距，中文无需强行拉开。

## 网页起始尺度

| 元素 | 建议 |
| --- | --- |
| 主画布 | 最大 1080px；桌面水平内距 36px，移动端 20px |
| H1 | 英文 36–60px / 1.1；中文可 34–54px / 1.3 |
| H2 | 28–39px / 1.15；中文行高约 1.3 |
| H3 | 无衬线 22–24px / 1.3，600 字重 |
| 导语 | 19–23px / 1.55–1.7 |
| 正文 | 桌面 17px / 1.8；移动端 16px / 1.8 |
| 辅助文字 | 13–14px / 1.6；关键条件必须不小于可读正文级别 |
| 正文段间距 | 约 20–24px |
| 大节间距 | 桌面 64px；移动端 40–44px |
| 表格 | 14–16px / 1.6；小屏允许受控横向滚动 |

正文宽度按语言和字号控制：英文约 60–75 字符，中文约 28–40 字符作为阅读起点，不挤满宽屏。PPT、海报、UI 需按 [制作指南](media-guides.md) 重设尺寸。

## 构图骨架

- 编辑式：短眉题 → 主标题与导语 → 主视觉 → 连续正文穿插图解 → 清晰的结束动作。
- 演示式：一句核心判断 + 一个支撑画面；连续页面在浅底、图文对开和深绿章节页之间变化。
- 海报式：主标题或主体占据注意力，辅助信息形成一个紧凑信息块；保留裁切与安全区。
- 界面式：导航和任务优先，主内容保留阅读宽度；只在首页或欢迎页使用展示型大标题。
- 图解式：先定义节点、关系与阅读顺序，再排线条和文字；装饰不能看起来像数据。

左对齐是稳妥起点；中心构图用于短封面、单句或单主体。尽量共用一条主对齐线。图片靠内容决定裁切，不能切掉重要结构或文字。

## 形状、材质与动效

圆角用 8 / 12 / 16 / 24px 的少数层级。网页图片可 14–16px，说明框约 16px，交互容器约 24px；印刷和 PPT 按实际尺度重设。大面积直角与少量圆角可以共存。

用 1px 细线和底色差区分层次，避免厚重投影。自然纸感只用于背景或图片，文字区域保持平整。线性图标采用一致线宽；箭头表达关系，而不是随处装饰。

UI 反馈动效可从 140–220ms 起步；尊重 prefers-reduced-motion。演示转场简单一致，静态海报不添加假动效标识。
