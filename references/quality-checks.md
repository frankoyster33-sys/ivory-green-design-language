# 验收清单

按实际交付媒介选择检查，不要求所有任务运行全部项目。

## 共通

- 标题、主视觉、辅助信息能否在一眼内分出主次？缩小预览时是否还成立？
- 字体实际存在且字形正确；中文无方框，混排标点和数字协调。
- 长标题、段落尾行、表格和脚注没有溢出、裁切、重叠或失去关联。
- 浅底正文、深底反白和交互状态有足够对比；含义不只靠颜色表达。
- 图表保留单位、刻度、图例和来源。抽象示意不伪装成真实数据。
- 所有公开素材有明确来源或为新建内容。检查可见文字，也检查注释、图层、隐藏内容、元数据和打包文件。
- 交付格式与声明一致；明确检查过的应用/设备，未实测的不声称兼容。

## 网页 / UI

检查桌面和窄屏布局、键盘 Tab 顺序、焦点可见、输入标签、错误提示、禁用态。交互的默认值、边界输入、重置和结果更新须可用。不能出现整页意外横向滚动；宽表格可以在独立容器中滚动。检查浏览器控制台和离线依赖；没有网络也应保留基础内容。

若需按 WCAG 验收，依据项目指定版本与级别核对；本模板提供设计起点，不等于整站无障碍认证。常用正文对比度目标为至少 4.5:1，控件边界和焦点应清楚可辨，实际按语境检查。参照 [W3C 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 和 [非文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

## PPT

逐页渲染检查，不只检视 XML。检查投影阅读距离、页码位置、图像清晰度、文本框溢出、母版一致性。在目标演示软件中检查字体替换和图表/动画行为。PPTX 中标题和正文应为可编辑文本；整页背景图只用于用户接受的例外。

## Photoshop / 海报

检查画布像素、印刷成品尺寸、分辨率、色彩配置、出血与安全区。文字和图像不越过安全区；图层命名和分组有意义，照片保留智能对象或原始副本（工具支持时）。输出预览图与分层源文件，印刷输出遵循印厂规范；未经打样不要声称屏幕颜色就是印刷颜色。

## 图像 / 图解

按实际使用尺寸检查。技术和数据图中的字、线、箭头、编号优先用矢量/代码排版；生成式图片里的文字与数值逐项复核，必要时后期叠字。无障碍描述应说明图像传递的信息，不只罗列颜色。
